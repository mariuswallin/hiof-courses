# l-15 — REST API-teori og arkitektur-prinsipper

Branch for leksjon 15 i `webapp-2025`.

Forstå REST som arkitektonisk stil, HTTP-metoder, status codes, URL-design og hvorfor disse prinsippene skaper skalerbare og vedlikeholdbare API-er

## Læringsmål

Se leksjonen i [`data/courses/webapp-2025/lessons/15-*.mdx`](../../../data/courses/webapp-2025/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
pnpm db:migrate:dev  # hvis Drizzle er konfigurert
pnpm dev
```

## Stack

- RedwoodSDK 1.3+
- React 19.2
- Drizzle ORM + Cloudflare D1
- TailwindCSS 4.3
- TypeScript 6
- Vite 8

Se `package.json` for nøyaktige versjoner.
