# l-18 — Mappers og DTO med forbedret Error Handling

Branch for leksjon 18 i `webapp-2025`.

Separere interne modeller fra API-kontrakter og verifisere robust error handling for vedlikeholdbare API-er

## Læringsmål

Se leksjonen i [`data/courses/webapp-2025/lessons/18-*.mdx`](../../../data/courses/webapp-2025/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
pnpm db:migrate:dev  # hvis Drizzle er konfigurert
pnpm dev
```

## Stack

- RedwoodSDK 1.3+
- React 19.2
- Drizzle ORM + Cloudflare D1
- TailwindCSS 4.3
- TypeScript 6
- Vite 8

Se `package.json` for nøyaktige versjoner.
