# drizzle-starter

Startmal for RedwoodSDK-prosjekt med Drizzle ORM, Cloudflare D1, better-auth
og TailwindCSS — alignet med stacken brukt i `ulearn-lms`.

## Komme i gang

```bash
pnpm install
pnpm db:migrate:dev
pnpm dev
```

Pek nettleseren mot adressen som vises i terminalen (typisk
`http://localhost:5173/`).

## Stack

- RedwoodSDK 1.3+
- React 19.2
- Drizzle ORM + Cloudflare D1
- better-auth
- TailwindCSS 4.3
- TypeScript 6, Vite 8
