# tailwind-starter

Startmal for RedwoodSDK-prosjekt med TailwindCSS (uten database).

## Komme i gang

```bash
pnpm install
pnpm dev
```

Pek nettleseren mot adressen som vises i terminalen (typisk
`http://localhost:5173/`).

## Stack

- RedwoodSDK 1.3+
- React 19.2
- TailwindCSS 4.3
- TypeScript 6, Vite 8

## Mer info

- [RedwoodSDK-dokumentasjon](https://docs.rwsdk.com/)
- [TailwindCSS v4](https://tailwindcss.com/docs/v4-beta)
