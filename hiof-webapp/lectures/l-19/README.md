# l-19 — Server Actions og forms med useActionState

Branch for leksjon 19 i `webapp-2025`.

Implementere Server Actions med React Server Components for moderne form håndtering som gjenbruker etablert Service Layer arkitektur

## Læringsmål

Se leksjonen i [`data/courses/webapp-2025/lessons/19-*.mdx`](../../../data/courses/webapp-2025/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
pnpm db:migrate:dev  # hvis Drizzle er konfigurert
pnpm dev
```

## Stack

- RedwoodSDK 1.3+
- React 19.2
- Drizzle ORM + Cloudflare D1
- TailwindCSS 4.3
- TypeScript 6
- Vite 8

Se `package.json` for nøyaktige versjoner.
