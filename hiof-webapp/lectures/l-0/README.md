# l-0 — Startpunkt for leksjon 02

Inneholder underprosjekter brukt i leksjon 02 (Grunnleggende webteknologier):

| Mappe | Innhold |
|---|---|
| `question-app/` | Komplett startpunkt for kursets question-app — bruker leksjonen som referanse |
| `css/`, `css-modern/` | Eksempler på vanlig vs. moderne CSS |
| `dom/` | DOM-API-eksempler |
| `forms/` | HTML-forms-eksempler |
| `json/` | JSON-håndtering |
| `loading/` | Load-states og resource hints |
| `server-html/`, `server-json/` | Forskjellen på server-rendret HTML vs. JSON-API |
| `public/` | Statiske ressurser |

## Kjør

Hvert underprosjekt har sin egen README/`index.html`. Åpne i nettleser eller
via en lokal HTTP-server:

```bash
npx serve question-app
```
