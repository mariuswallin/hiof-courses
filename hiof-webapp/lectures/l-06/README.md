# l-06 — React komponenter med søk og filtrering

Branch for leksjon 06 i `webapp-2025`.

Bygg en interaktiv React-komponent med TypeScript som håndterer søk, filtrering og state management. Lær grunnleggende arkitektur-prinsipper og identifiser utfordringer ved skalering.

## Læringsmål

Se leksjonen i [`data/courses/webapp-2025/lessons/06-*.mdx`](../../../data/courses/webapp-2025/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
pnpm db:migrate:dev  # hvis Drizzle er konfigurert
pnpm dev
```

## Stack

- RedwoodSDK 1.3+
- React 19.2
- Drizzle ORM + Cloudflare D1
- TailwindCSS 4.3
- TypeScript 6
- Vite 8

Se `package.json` for nøyaktige versjoner.
