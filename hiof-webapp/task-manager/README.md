# task-manager

Demo-prosjekt for task-manager. Bruker RedwoodSDK + Tailwind som base.

## Komme i gang

```bash
pnpm install
pnpm dev
```

Åpne adressen som vises i terminalen (typisk `http://localhost:5173`).

## Stack

- RedwoodSDK 1.3+
- React 19.2
- TailwindCSS 4.3
- Vite 8
- TypeScript 6

Se `package.json` for nøyaktige versjoner.
