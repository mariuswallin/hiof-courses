# l-29 — Drawer navigation

Branch for leksjon 29 i `react-native`.

Implementere drawer-navigation med Expo Router. Bildevalg er flyttet til leksjon 28 (Filer og bilder).

## Læringsmål

Se leksjonen i [`data/courses/react-native/lessons/29-*.mdx`](../../../data/courses/react-native/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
npx expo install --check
pnpm start
```

For native builds:

```bash
npx expo run:ios
npx expo run:android
```

## Stack

- Expo SDK 55
- React Native 0.83
- React 19.2
- expo-router 7
- TypeScript 5.9
