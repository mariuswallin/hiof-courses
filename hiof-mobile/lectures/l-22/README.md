# l-22 — Context API for global tilstand

Branch for leksjon 22 i `react-native`.

Administrere global tilstand med React Context API.

## Læringsmål

Se leksjonen i [`data/courses/react-native/lessons/22-*.mdx`](../../../data/courses/react-native/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
npx expo install --check
pnpm start
```

For native builds:

```bash
npx expo run:ios
npx expo run:android
```

- Expo SDK 55
- React Native 0.83
- React 19.2
- expo-router 7
