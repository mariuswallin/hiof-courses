# l-27 — API-integrasjon: mutations, custom hooks og paginering

Branch for leksjon 27 i `react-native`.

Bygg custom hooks rundt TanStack Query for CRUD-operasjoner, paginering og infinite scroll. Konsoliderer mutasjons- og paginerings-temaene fra tidligere versjoner av kurset.

## Læringsmål

Se leksjonen i [`data/courses/react-native/lessons/27-*.mdx`](../../../data/courses/react-native/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
npx expo install --check
pnpm start
```

For native builds:

```bash
npx expo run:ios
npx expo run:android
```
