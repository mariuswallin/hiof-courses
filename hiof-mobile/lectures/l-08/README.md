# l-08 — Props og komponentkommunikasjon

Branch for leksjon 08 i `react-native`.

Lær hvordan komponenter kommuniserer gjennom props.

## Læringsmål

Se leksjonen i [`data/courses/react-native/lessons/08-*.mdx`](../../../data/courses/react-native/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
npx expo install --check
pnpm start
```

For native builds:

```bash
npx expo run:ios
npx expo run:android
```

## Stack

- Expo SDK 55
- React Native 0.83
- React 19.2
- expo-router 7
- TypeScript 5.9
