Branch for leksjon 25 i `react-native`.

## Læringsmål

Se leksjonen i [`data/courses/react-native/lessons/25-*.mdx`](../../../data/courses/react-native/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
npx expo install --check
pnpm start
```

For native builds:

```bash
npx expo run:ios
npx expo run:android
```
