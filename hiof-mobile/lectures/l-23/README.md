# l-23 — Autentisering del 1 - grunnleggende

Branch for leksjon 23 i `react-native`.

Implementere brukeautentisering i React Native.

## Læringsmål

Se leksjonen i [`data/courses/react-native/lessons/23-*.mdx`](../../../data/courses/react-native/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
npx expo install --check
pnpm start
```

For native builds:

```bash
npx expo run:ios
npx expo run:android
```
