# l-10 — Brukerinteraksjoner

Branch for leksjon 10 i `react-native`.

Håndtere berøring, trykk og andre brukerinteraksjoner.

## Læringsmål

Se leksjonen i [`data/courses/react-native/lessons/10-*.mdx`](../../../data/courses/react-native/lessons/) for fullstendige læringsmål og oppgaver.

## Kjør lokalt

```bash
pnpm install
npx expo install --check
pnpm start
```

For native builds:

```bash
npx expo run:ios
npx expo run:android
```

## Stack

- Expo SDK 55
- React Native 0.83
- React 19.2
- expo-router 7
- TypeScript 5.9
