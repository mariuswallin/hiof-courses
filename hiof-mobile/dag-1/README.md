# dag-1

Demo-prosjekt fra dag 1 av kurset. Expo + expo-router.

## Komme i gang

```bash
pnpm install
pnpm start
```

Velg target i Expo CLI (iOS simulator / Android emulator / Expo Go).

## Stack

- Expo SDK 55
- React Native 0.83
- expo-router 7
- TypeScript 5.9

## Mer info

- [Expo-dokumentasjon (no)](https://docs.expo.dev/)
- File-based routing: se `app/`-mappa
