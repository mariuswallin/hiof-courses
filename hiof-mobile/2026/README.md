Leksjonene i [`../lectures/`](../lectures) er på SDK 56. Denne mappa ligger ett
hakk foran, men uten breaking changes: React Native 0.85 til 0.86 og React 19.2
uendret, så alle mønstrene fra leksjonene gjelder ordrett.

Merk at Expo Go for SDK 56 og 57 ikke kan installeres samtidig. Bruk emulator
for prosjektene her.
